# orders-service

Минимальный демо-сервис заказов на Spring Boot 3 и Java 21: стартовая точка для демонстрации AI-пайплайна.
Заказы хранятся в памяти, при старте доступны заказы с id `1` и `2`.
Единственный эндпоинт: `GET /orders/{id}` возвращает заказ (200) или 404, если заказа нет.

Сборка и тесты (нужна Java 21, Maven скачивается через wrapper): `./mvnw verify`.
Запуск: `./mvnw spring-boot:run`, затем `curl localhost:8080/orders/1`.
